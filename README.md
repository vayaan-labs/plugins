# Vayaan Labs plugins

The catalogue of Claude Code plugins and mods from Vayaan Labs.

Add it once and every plugin here stays up to date:

- In the Claude desktop app: Directory, Plugins, the + button, Add from a repository, then `vayaan-labs/claude-plugins`.
- In the terminal: `claude plugin marketplace add vayaan-labs/claude-plugins`

Then install a plugin by name, for example `claude plugin install cache-maxxer@vayaan-labs`.

| Plugin | What it does |
|---|---|
| [cache-maxxer](https://github.com/vayaan-labs/cache-maxxer) | Shows the prompt cache's countdown and hit rate above the prompt, explains every cache break, and can keep the cache warm on purpose |
